# CPU Scheduling and MultiCore
Now we are here with the fun part of this project: Creating a CPU Scheduler and implementing a multi-core implementation. This will be a challenge but the performance will be there. In this module, we will implement multiple things to get this to work. We will need to enable the MMU for the caching and virtual addresses. Afterwards, we can implement the memory allocator that's required for threading. Finally, we can develop the scheduler for one core.
